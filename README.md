# Multi-Modal AI Framework for Early Parkinson's Disease Screening

## 📌 Overview

This project proposes a **Multi-Modal AI Framework** for early screening of Parkinson's Disease (PD) using multiple non-invasive modalities:

* 🎙️ Voice
* ✍️ Handwriting
* 🚶 Gait
* ✋ Hand Tremor
* 🙂 Facial Analysis

The system uses AI/ML models to analyze these modalities individually and combines their predictions using **multimodal fusion** to generate an overall risk assessment.
